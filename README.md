# Doubly Linked List Mini Lab

Repositori ini dibuat untuk tugas kelompok praktikum Struktur Data mengenai Doubly Linked List. Fokus utama tugas ini adalah memahami bagaimana pointer prev dan next bekerja saat melakukan penelusuran dua arah, menyisipkan data di tengah, serta menghapus node.

## Struktur Folder
- src/main.cpp : Program utama untuk tugas 1 sampai 6 serta menu manual.
- experiments/ : Berisi kode eksperimen lanjutan (Task 7).
- ss/ : Tempat menyimpan tangkapan layar hasil running program.
- AI-NOTES.md : Catatan dokumentasi penggunaan AI sesuai instruksi tugas.
- REFLECTION.md : Catatan refleksi individu masing-masing anggota.

## Cara Menjalankan Program

### 1. Program Utama (Task 1 - 6)
Kompilasi dan jalankan file main.cpp:
```bash
g++ src/main.cpp -o main.exe
./main.exe
```
